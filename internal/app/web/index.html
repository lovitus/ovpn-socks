OpenVPN 如何使用

导入或粘贴包含证书的 .ovpn，填写账户信息后启动。将应用的 SOCKS5 代理指向对应端口；域名解析也走 VPN。下发的路由可直接复制，用于配置你自己的 tun2socks 等工具。

默认端口从 0.0.0.0:1080 开始分配。当前支持 SOCKS5 TCP CONNECT，暂不支持 UDP ASSOCIATE。未连接时不会转发流量。

OpenVPN protocol → gVisor netstack → SOCKS5 多接口监听 · 加密存储 · 默认自动重连

新建连接

每次认证自动生成新的验证码，支持带 = 填充的 seed。

配置按原生引擎语义解析。内联配置自动作为配置文件传入；已有配置参数时使用 {config} 指向此内容。外部引擎默认使用宿主机网络，不会自动进入 VPN。

仅解析配置，不启动连接；声明地址不代表已经监听。

配置与凭据加密保存在本机。修改运行中的连接前请先停止。OpenVPN 无需 TAP/TUN；外部引擎按原生配置运行。
